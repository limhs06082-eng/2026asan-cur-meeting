# 교육과정 연결 협의 웹앱 사용 안내 (선생님용)

접속: https://asan-curriculum-link-2026.web.app

## 0. 처음 접속
1. Google 계정으로 로그인합니다.
2. ‘접근 요청 보내기’에 학년·역할을 적어 보냅니다(예: 3학년 대표).
3. 관리자가 승인하면 화면이 자동으로 바뀝니다. 공용 노트북은 끝나면 오른쪽 위 ‘로그아웃’을 누릅니다.

## 1. 우리 학년 카드 정비 (학년 편집자·대표)
- ‘전체 보드’에서 우리 학년 열의 카드를 누르면 오른쪽에 상세 패널이 열립니다.
- **카드 수정**: 실제 운영에 맞게 활동명, **배움의 목적**(필수), 대표 영역, 영역 태그, 주제, 배움·자람·나눔, 운영 정보(시기·실제 편성 영역 등)를 고치고 ‘저장’합니다.
  - 학생 이름·성적·상담 내용은 적지 않습니다.
  - ‘원본 해석 확인 메모’(예: 한 칸에 두 활동)는 확인했으면 ‘확인 완료로 지우기’를 누릅니다.
- **새 활동 추가**: 학년 열 머리의 ‘+’ 또는 빈 칸의 ‘+’. 원본에 없는 활동은 추가 이유를 적습니다.
- **활동 제외**: 운영하지 않는 활동은 ‘활동 제외’ + 이유. 삭제가 아니라 기록으로 남고 ‘복원’할 수 있습니다.
- **중복 후보**: 상세 패널에 비슷한 이름의 같은 학년 카드가 보이면 ‘별도 활동임’ 또는 ‘이 카드로 합치기’를 고릅니다. 자동으로 합치지 않습니다.
- **사실 확인**: 카드 내용이 실제 운영과 맞으면 **‘실제 운영과 맞음 — 확인’**. 나중에 카드가 바뀌면 확인이 자동으로 풀립니다.

## 2. 연결 이유 쓰기
- 카드 상세 → **‘연결 만들기’** → 보드에서 도착 카드를 누릅니다. (또는 ‘목록에서 연결 고르기’로 키보드로 검색해 고릅니다.)
- 연결 종류:
  - **배움의 심화**(방향 있음): 앞 카드에서 경험한 것 / 뒤 카드에서 깊어지는 것. 학년을 건너뛰면 이유를 적습니다.
  - **학년 간 공동활동**: 학년별 역할 / 함께 확인할 결과 (예: 2학년과 6학년 세계 여행)
  - **공통 운영**: 공통 목표 / 학년별로 달리 운영할 범위
- 모든 연결에 ‘왜 연결하는가’를 적습니다. 연결 개수는 성과가 아닙니다.
- **독립 운영**: 따로 운영할 이유가 있는 활동(입학·졸업 등)은 상세 패널 ‘판단 기록하기’ → 독립 운영 + 이유. 학년 대표가 확인하면 ‘독립 운영 합의’가 됩니다.

## 3. 학년 확인 (학년 대표)
- ‘연결’ 화면에서 연결을 눌러 **‘○학년 대표로 확인’**. 관련 학년이 모두 확인해야 ‘연결 합의’입니다. 같은 학년 안 연결은 그 학년 확인으로 충분합니다.
- 연결이나 양 끝 카드가 바뀌면 ‘재확인 필요’로 바뀝니다. 다시 읽고 확인합니다.
- ‘학년 정비’ 화면: 모든 카드의 목적과 사실 확인이 끝나면 **‘우리 학년 확인 완료’**.

## 4. 2027안
- 관리자가 2026 확인본을 확정하고 2027 개편안을 만듭니다. 학년은 자동으로 올라가지 않습니다(2026 1학년 카드 → 2027 1학년 카드).
- 모든 카드는 ‘유지’ 제안·미확인 상태로 시작합니다. 카드 수정에서 **변경 유형(유지·수정·추가·종료)과 이유**를 적고, 다시 사실 확인·연결 확인을 받습니다. 종료 활동은 지우지 않고 ‘종료’로 표시합니다.
- 의견이 갈리거나 나중에 정할 일은 ‘점검·제안’에서 **제안**으로 남기고 수용·보류·반려와 이유를 기록합니다. ‘다음 학년도 전달’을 표시하면 이듬해 작업본으로 넘어갑니다.

## 5. 출력
- ‘출력’ → 한눈에 보기(A3 가로 / A4 분할) 또는 연결 설명·변경 기록 → ‘출력 화면 만들기’ → ‘인쇄 / PDF로 저장’.
- 인쇄 창에서 대상 ‘PDF로 저장’, 용지 A3(또는 A4) 가로, 배경 그래픽 켬.
- 확정 전 출력에는 ‘협의 중 초안’이 표시됩니다.

## 저장 표시
- **서버 저장 확인**: 저장 완료.
- **충돌**: 다른 선생님이 먼저 고쳤습니다. 내 초안은 남아 있고, ‘합친 내용으로 양식 채우기’ 후 다시 저장합니다.
- **연결 불안정**: 저장되지 않았을 수 있습니다. 같은 버튼을 다시 누르면 안전하게 재시도합니다(두 번 저장되지 않음).
- **권한 없음**: 담당 학년·역할 밖이거나 확정·준비 중인 작업본입니다.
